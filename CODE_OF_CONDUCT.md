# Code de conduite

Breathly est un projet ouvert à toute personne, quels que soient son niveau, son âge, son origine ou sa langue. Ce code dit comment nous travaillons ensemble dans les issues, les PR, les revues et tout espace du projet.

## Notre engagement

- Parler avec respect, y compris en désaccord. On critique le code, pas la personne.
- Accueillir les débutants : une question simple mérite une réponse simple.
- Écrire clairement. Le français et l'anglais sont acceptés ; une traduction approximative est mieux que le silence.
- Reconnaître une erreur, la corriger, passer à la suite.

## Comportements inacceptables

- Insultes, harcèlement, discrimination, propos haineux ou sexualisés.
- Attaques personnelles, moqueries, menaces, publication de données privées d'autrui sans accord.
- Insistance après un refus, pression pour fusionner ou répondre.
- Tout comportement qu'on n'aurait pas devant la personne concernée.

## Application

Les mainteneurs peuvent modifier, masquer ou supprimer un commentaire, une issue ou une PR qui ne respecte pas ce code, et écarter temporairement ou durablement une personne. Ils expliquent leur décision par écrit, sauf si cela expose la personne qui a signalé.

## Signaler un problème

Écrire aux mainteneurs : aresgnimagnon0@gmail.com (propriétaire du dépôt). Le signalement reste confidentiel. Un mainteneur mis en cause ne traite pas le signalement qui le concerne.

## Portée et sources

Ce code s'applique dans les espaces du projet et quand une personne le représente publiquement. Il s'inspire de l'idée du *Contributor Covenant* (<https://www.contributor-covenant.org/>) sans en reprendre le texte.
