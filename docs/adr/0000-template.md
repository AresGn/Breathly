# ADR 0000 : Titre de la décision

- **Statut** : en attente | proposé | accepté | remplacé par ADR XXXX
- **Date** : AAAA-MM-JJ
- **Décideurs** : (qui valide, côté client et côté équipe)

## Contexte

Quel problème, quelles contraintes, quelles sources (cahier des charges, PRD, échanges). Ce qui a été **vérifié** (avec la page de documentation lue et la date) et ce qui est **non vérifié**.

## Options

1. Option A : avantages / coûts
2. Option B : avantages / coûts

## Décision

L'option retenue et pourquoi. Tant que le statut est « en attente », indiquer l'hypothèse de travail.

## Conséquences

Ce que ça impose dans le code (ports, modules, tickets), ce qui devient plus facile, ce qui devient plus difficile.

## Impact sur l'architecture

Port(s) concerné(s), module(s), migration éventuelle si la décision change plus tard.
