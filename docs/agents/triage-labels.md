# Étiquettes de triage

Les skills parlent de cinq rôles de triage. Ce fichier les associe aux étiquettes de ce dépôt (GitHub).

| Étiquette dans les skills | Étiquette ici | Sens |
|---|---|---|
| `needs-triage` | `needs-triage` | le mainteneur doit évaluer le ticket |
| `needs-info` | `needs-info` | en attente d'informations de la personne qui l'a ouvert |
| `ready-for-agent` | `ready-for-agent` | entièrement spécifié, prêt pour un agent autonome |
| `ready-for-human` | `ready-for-human` | demande une implémentation ou une décision humaine |
| `wontfix` | `wontfix` | ne sera pas traité |

Quand une skill cite un rôle (« l'étiquette prêt pour un agent »), utiliser l'étiquette de ce tableau.

Rôles de catégorie : `bug` et `enhancement` (étiquettes GitHub par défaut). Étiquettes propres au projet (`app:*`, `en-attente-decision`) : `docs/agents/issue-tracker.md`.

**Aucune mention d'outil dans les commentaires de triage** : l'avertissement « généré par IA » que la skill `triage` ajoute par défaut est supprimé ici (`CONTRIBUTING.md` §11).
