# Recherches

Une recherche est une note **datée** qui fonde une décision (cadre légal, fournisseur, comparaison d'outils). Nom de fichier : `AAAA-MM-JJ-sujet.md`. On n'écrase jamais une recherche : on en ajoute une nouvelle, datée, qui la complète ou la corrige.

Chaque note dit : la question posée, les sources lues (URL et date de lecture), ce qui est **vérifié**, ce qui est **non vérifié**, et la décision (ADR) qu'elle alimente.
