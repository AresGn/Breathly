# Génération des types TypeScript depuis Rust : essai de ts-rs, 2026-10-18

Alimente l'ADR 0016 (ticket #27).

## Question

Comment générer les types échangés entre le cœur et l'interface (jamais écrits à la main, design 0002 §6) et vérifier en CI qu'ils sont à jour ?

## Essai de ts-rs 12.0.1

Projet isolé hors dépôt, sources et fichiers produits dans `types-typescript-2026-10-18/`. Types d'essai représentatifs du contrat : newtype `ByteSize(u64)`, énumération à variantes simples `RiskLevel`, union à balise `Progress` (`#[serde(tag = "kind")]`, variantes avec champs et `Option`), structure avec `Vec`, `Option` et un `u64`.

| Cas | Résultat |
|---|---|
| Union à balise | union TypeScript correcte : `{ "kind": "started" } \| { "kind": "step", done: number, total: number \| null, step_key: string, } \| …` |
| Énumération simple avec `rename_all = "snake_case"` | `"safe" \| "review" \| "personal"` |
| Newtype avec `#[ts(type = "number")]` | `export type ByteSize = number;` |
| `Option<T>` | `T \| null` |
| `u64` | **`bigint` par défaut** (faux à l'exécution : `serde_json` produit un nombre) ; **`number`** avec `TS_RS_LARGE_INT=number` |
| Dossier de sortie | `TS_RS_EXPORT_DIR` (défaut `./bindings`) |
| En-tête des fichiers | « This file was generated by ts-rs. Do not edit this file manually. » |
| Mode d'emploi | `cargo test` exporte les fichiers (un test par type) |
| `ts-rs` en dépendance de développement avec `#[cfg_attr(test, derive(ts_rs::TS))]` et `#[cfg_attr(test, ts(...))]` | génération correcte ; **`ts-rs` absent de l'arbre de dépendances normal** (`cargo tree -e normal` : 0) |
| `cargo deny check bans sources` (avec le `deny.toml` du dépôt) | passe ; arbre de `ts-rs` : `ts-rs`, `ts-rs-macros`, `termcolor`, `thiserror`, bibliothèques de macros déjà présentes pour la plupart |

La documentation du crate (en-tête de `lib.rs` de ts-rs 12.0.1) donne les variables `TS_RS_EXPORT_DIR` (défaut `./bindings`) et `TS_RS_LARGE_INT` (défaut `bigint`), et leur usage dans `.cargo/config.toml` (`[env]`, `relative = true`).

## Non vérifié

- `tauri-specta` en release candidate, `typeshare`, `schemars` + npm : non essayés ; seuls leurs métadonnées de crates.io et leurs versions sont relevées.
- Les types génériques, `Duration`, `PathBuf` : le contrat n'envoie jamais de chemin (SEC3) ; les durées sont des nombres.
- La précision d'un `u64` au-delà de 2^53 (environ 9 pétaoctets) : sans objet pour des tailles de fichiers.
- Le comportement de `ts-rs` sous Windows (chemins de sortie) : non essayé.
